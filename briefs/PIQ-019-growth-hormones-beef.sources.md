# PIQ-019 sources (checked 2026-09-27)

Story: steroid hormone growth implants in US beef cattle (oestradiol 17β, progesterone,
testosterone, trenbolone acetate, zeranol) and the oral feed additive melengestrol
acetate (MGA). This is a different substance class from PIQ-007 (ractopamine, a
beta-agonist administered in feed). See Notes for how the two stories stay separate.

Notes
- **How this differs from PIQ-007 (ractopamine):** ractopamine is a beta-agonist, fed continuously in the ration during the last weeks before slaughter, banned in the EU under 96/22/EC Annex II, List B ("beta-agonists"). This story's five implant/feed-additive hormones (oestradiol 17β, progesterone, testosterone, trenbolone acetate, zeranol, plus the oral additive melengestrol acetate) are steroid/hormonal growth promoters, administered as a subcutaneous ear implant (all but MGA, which is an oral feed additive), and sit in a different part of the same EU directive: oestradiol 17β is Annex II List A (banned outright, no growth-promotion derogation at all); the other five fall under Annex III as a class ("oestrogenic other than oestradiol 17β, androgenic, or gestagenic action" — provisionally prohibited). Both stories can cite the same import rule (Delegated Regulation 2022/2292, Article 10) because that one article's wording separately bans beta-agonists AND stilbene/thyrostatic/oestrogenic/androgenic/gestagenic substances — it is one shared citation for a rule that legitimately covers both substance classes, not a duplicated story.
- Fetch methods: eur-lex.europa.eu, fsis.usda.gov, and www.wto.org return blank content to the direct WebFetch tool (empty page) and fsis.usda.gov/govinfo-hosted PDFs return HTTP 403 to command-line curl; the HTML pages (eur-lex directive texts, the WTO case page, FSIS's labeling-terms and residue-program pages) were read successfully in the browser (Claude in Chrome) as rendered text. The two FSIS PDF/xlsx documents (chemical-residue class list; quarterly Data_QSR_Tolerances datasets) would not render as extractable text in the in-browser PDF viewer (blank/canvas-only, and the viewer's own download control did not produce a file), so those two were read through a text-extraction reader proxy (r.jina.ai) fetching the same fsis.usda.gov URLs — the content is the primary FSIS document, just accessed through a different retrieval path than direct download. eCFR (ecfr.gov versioner API) was fetched directly, no redirect to unblock.federalregister.gov occurred or was followed anywhere in this research.
- The FDA's "increment above natural baseline" tolerance structure for estradiol/progesterone/testosterone, and the "Not required" tolerance for trenbolone/zeranol in cattle edible tissue, likely explain why FSIS's own multi-residue screening method has no real "steroid implant" testing class the way it has a "Beta-Agonists" class for ractopamine/zilpaterol/clenbuterol: there is no fixed numeric limit to screen most of these compounds against. This is inference from the primary sources above, not itself a quoted claim from any single source — present it as inference if used.
- Zero rows in two quarterly datasets is not proof of zero use or zero residue; as with the PIQ-007 ractopamine data, these files list only rows already classified "Detected, Non-Violative" or "Violative," with no published count of samples tested with nothing found, so no detection rate or testing-frequency claim can be derived. It is not confirmed whether FSIS tests for these six hormone-related compounds at all in routine surveillance, only that FSIS's own public class list names three of them (melengestrol acetate, prednisone, taleranol) under one testing method and not the other five compounds by name.
- Not confirmed / cut: any USDA AMS Process Verified Program wording specific to "never fed hormones" claims (not checked for this brief, unlike the ractopamine post's AMS PVP listing); any numeric EU or Codex MRL for these hormones (not located; Codex's veterinary drug database was not checked for this story); the exact substance list in the original 1988 EU hormone ban texts (88/146/EEC, 88/299/EEC) beyond what 81/602/EEC and 96/22/EC already establish, since both were not read directly (they are superseded and their operative substance list is carried into 96/22/EC's Annex II/III, which was read); whether the WTO/EU dispute documents themselves enumerate the "six specific hormones" by name (only the phrase itself was found in the WTO case summary; the actual six-substance list here rests on the EU directive and FDA/FSIS sources, not the WTO page).
